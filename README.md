# تسعير مخزون العطور

صفحة واحدة للبحث والمقارنة وتسعير مخزون العطور ومستحضرات التجميل الكورية،
مبنية من قائمة المورد (Stock Fragancias).

بيانات المورد **مشفّرة** داخل `payload.js` بـ AES-256-GCM ومفتاح مشتقّ من كلمة المرور
عبر PBKDF2 (210k تكرار). لا يوجد في هذا المستودع أي سعر بصيغة مقروءة.

## الملفات
| الملف | الدور |
|---|---|
| `index.html` | الصفحة المنشورة (تُبنى آلياً — لا تحرّرها مباشرة) |
| `shell.part` | الواجهة والتنسيق — المصدر الحقيقي للتحرير *(محلي)* |
| `app.js` | منطق التطبيق: الحساب، الفلترة، الجدول، المقارنة |
| `payload.js` | البيانات مشفّرة |
| `data.js` | البيانات الخام *(محلي فقط، غير مرفوع)* |
| `build.py` | يبني `index.html` و`dist.html` من المصدر |

## البناء
```bash
python3 build.py                          # إعادة بناء بنفس التشفير الحالي
python3 build.py --password "كلمة جديدة"   # إعادة تشفير البيانات بكلمة مرور جديدة
```
